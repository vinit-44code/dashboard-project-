# 📋 Work-Flow Dashboard

A modern productivity dashboard built with **React.js** that combines multiple productivity tools into a single application. Instead of creating separate projects, this dashboard integrates a **Notes App**, **Task Manager**, and **Weather Application** to provide a unified workspace.

---

## ✨ Features

### 📝 Notes

* Create notes
* Edit existing notes
* Delete notes
* Search notes by title
* Created date and last updated date
* Responsive note cards

### ✅ Task Manager

* Add new tasks
* Mark tasks as completed
* Filter tasks (All / Pending / Completed)
* Categorize tasks
* Due date selection
* Clean popup interface for task creation

### 🌤 Weather

* Search weather by city
* Live weather information using Open-Meteo API
* Displays:

  * City name
  * Current temperature
  * Weather condition
* Uses Geocoding API to fetch city coordinates before retrieving weather data

```bash

```

